# Pantallas de escritorio

Son 7 pantallas pensadas para 1440 × 900 px, en el orden del flujo. Abre cada archivo en un navegador con la ventana a ese ancho.

| Archivo | Pantalla | Disposición | Enlaza con |
| --- | --- | --- | --- |
| `DeskInicio.html` | Inicio | Sin barra lateral ni chat: es la página de entrada | DeskAsistenteInicio, DeskCrearCuenta |
| `DeskAsistenteInicio.html` | Asistente sin ruta, chat a todo el ancho | Sin panel derecho: el chat ocupa todo el espacio libre | DeskAjustes, DeskAsistenteCreando, DeskAsistenteRuta, DeskMisRutas |
| `DeskAsistenteCreando.html` | Asistente creando la ruta | Sin panel derecho: el progreso va dentro del chat | DeskAjustes, DeskAsistenteRuta, DeskMisRutas |
| `DeskAsistenteRuta.html` | Ruta terminada, a la derecha | Chat estrecho y ruta a la derecha | DeskAjustes, DeskCrearCuenta, DeskMisRutas |
| `DeskCrearCuenta.html` | Diálogo de crear cuenta | Diálogo sobre la vista anterior, atenuada | DeskAjustes, DeskAsistenteRuta, DeskMisRutas |
| `DeskMisRutas.html` | Mis rutas desplegado | Desplegable abierto en la barra lateral; ruta guardada a la derecha | DeskAjustes, DeskAsistenteCreando, DeskAsistenteRuta |
| `DeskAjustes.html` | Perfil con chat visible | Ajustes en el panel derecho; el chat sigue visible | DeskAsistenteCreando, DeskAsistenteRuta, DeskMisRutas |
